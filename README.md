# LLM_Benchmark_Dev_Loop
Benchmark prompts and evaluation prompts to test LLM's abilities. These evaluations need to be scored by a top SOTA LLM.

Have the tested LLM execute the xxx_benchmark.md file.

Have the SOTA model read the xx_evaluation.md file and point it to where the tested LLM put its work.

Note that by default, the tested LLM is told to place its work in /appdata/LLM_Benchmark_2026MMDD/ but you can edit the md file to put in your own preferred folder.
